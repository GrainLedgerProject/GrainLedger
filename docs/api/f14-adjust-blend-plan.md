# Adjust blend plan

Export Staff with BlendPropose and ResidueEvaluate permissions can edit an unproposed draft after a passing Calculate preview. Edit allocations loads every candidate page for the same scoped revision. Add a lot/location, remove a row, or enter positive whole kilograms. Input total must remain unchanged; this preserves the basis input quantity while F14 checks the applicable output yield again. Removing the last broken-rice row can switch to an approved head-only compatibility rule; no new rule is invented.

`POST /api/blend-plans/{id}/preview` accepts `planAdjustment: { previewReference, allocations: [{ lotId, locationId, quantityKg }] }`. Quantity is a decimal string containing whole kg. The manual mode and the existing two-lot `adjustment` mode are mutually exclusive. The basis must belong to the current company, actor and draft, be unexpired, and match facility, scope and priority. Backend resolves identities and revisions from the current scoped snapshot, then reuses F14 validation, source-lab requirements, per-input MRL screening, F12 output residue calculation, quality, yield and freshness checks.

Editing disables Save proposal and hides the prior assessment. A failed check stays editable and displays its findings; it issues no proposal reference. A passing check replaces the preview with a fresh reference and allows the existing Save proposal action. Manual changes are not claimed to be optimal. Cancel adjustment explicitly restores the previous unchanged preview while it remains current. No adjustment moves or reserves stock; the existing proposal and approval rechecks remain authoritative. No migration or seed is required.
